# ⌨️ Keybindings Reference for mangoWM

Here is the complete list of keybindings configured in this setup.

> **Note:** The `SUPER` key is usually the **Windows / Command** key on your keyboard.

---

## 🚀 System & Session
| Keybinding | Action |
| :--- | :--- |
| `SUPER` + `SHIFT` + `R` | Reload mangoWM configuration |
| `SUPER` + `CTRL` + `L` | Lock screen (`swaylock-effects` with blur) |
| `SUPER` + `M` | Quit / Exit mangoWM |

---

## 📱 Applications & Utilities
| Keybinding | Action |
| :--- | :--- |
| `SUPER` + `Q` | Launch Kitty terminal |
| `ALT` + `T` | Launch Kitty terminal |
| `SUPER` + `A` | Launch Rofi application launcher |
| `SUPER` + `TAB` | Launch Rofi application launcher |
| `SUPER` + `E` | Launch Yazi file manager |
| `SUPER` + `SHIFT` + `S` | Take area screenshot & copy to clipboard |
| `Print` | Take area screenshot & copy to clipboard |
| `SUPER` + `SHIFT` + `+` | Show keybindings helper script |

---

## 🖼️ Window Management
| Keybinding | Action |
| :--- | :--- |
| `SUPER` + `C` | Close focused window |
| `SUPER` + `F` | Toggle fullscreen mode |
| `SUPER` + `Space` | Toggle floating mode for focused window |
| `ALT` + `Tab` | Enter workspace / window overview |
| `SUPER` + `Left Click` *(Hold)* | Drag / Move floating window |
| `SUPER` + `Right Click` *(Hold)* | Resize floating window |

---

## 🎯 Navigation & Window Movement

### Changing Focus
| Keybinding | Action |
| :--- | :--- |
| `SUPER` + `H` / `Left Arrow` | Focus window on the left |
| `SUPER` + `J` / `Down Arrow` | Focus window below |
| `SUPER` + `K` / `Up Arrow` | Focus window above |
| `SUPER` + `L` / `Right Arrow` | Focus window on the right |

### Moving Windows
| Keybinding | Action |
| :--- | :--- |
| `SUPER` + `SHIFT` + `H` / `Left Arrow` | Swap window position to the left |
| `SUPER` + `SHIFT` + `J` / `Down Arrow` | Swap window position down |
| `SUPER` + `SHIFT` + `K` / `Up Arrow` | Swap window position up |
| `SUPER` + `SHIFT` + `L` / `Right Arrow` | Swap window position to the right |

---

## 🔢 Workspaces (Tags)

| Action | Workspace 1–9 |
| :--- | :--- |
| **Switch Workspace** | `SUPER` + `1`–`9` |
| **Move Window to Workspace** | `SUPER` + `SHIFT` + `1`–`9` |
